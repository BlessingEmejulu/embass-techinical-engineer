# Embass Tech

Embass Tech is a responsive business website for Embass Technical Engineering Services, a family-run water engineering and plumbing company based in Nnewi, Anambra State, Nigeria. The company has provided services since 1996 and works with residential, commercial and institutional clients.

The website introduces the company, explains its services, shares project imagery and client testimonials, and gives prospective customers direct ways to get in touch.

## Services featured

- Borehole drilling
- Borehole installation, maintenance and repair
- Overhead water tank construction
- Internal and external plumbing

## Website features

- Responsive layouts for desktop and mobile
- Company history and experience statistics
- Service and project galleries
- Client testimonials
- Contact details, location map and quote enquiry form
- Click-to-call and WhatsApp contact links
- Quote form that validates the enquiry and opens WhatsApp with a pre-filled message

> The enquiry form does not submit to a website backend. It prepares a message and hands it off to WhatsApp so the visitor can send it to Embass Tech.

## Getting started

This is a static website. It has no build step or package installation.

1. Clone or download this repository.
2. Open `index.html` in a browser.

For local development, serve the project directory with a local web server. For example, if Python is installed:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## External resources

The page loads Google Fonts, Font Awesome, Swiper and the embedded Google Map from external services. An internet connection is needed for those resources. The website itself does not require a JavaScript framework or a backend server.
